# 开发环境搭建

## 前置要求

- Node.js ≥ 20
- npm

## 安装与启动

```bash
cd points-card-manager
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 启动开发服务器（HMR） |
| `npm run build` | TypeScript 检查 + Vite 生产构建 |
| `npm run preview` | 本地预览构建产物 |
| `npm run build && npm run preview` | 构建并预览 |

## 构建验证

```bash
npm run build
```

产物输出到 `points-card-manager/dist/`：
- `index.html`
- `assets/index-{hash}.js`
- `assets/index-{hash}.css`

## 根目录验证脚本

```bash
python3 poc_verification.py
```

自动检查文件完整性、依赖配置、TypeScript 编译、Vite 构建。
