# 编码规范

## TypeScript

- 优先使用 `interface` 而非 `type` 描述对象类型
- 避免 `any`，使用 `unknown` 并在使用时断言
- 函数参数和返回值必须显式声明类型
- 使用 `const` 而非 `let`（除非需要重新赋值）

## React

- 组件使用函数组件 + Hooks，不使用 class 组件
- 每个组件一个文件，文件名与组件名一致（PascalCase）
- Props 接口定义在文件底部或独立 `types/` 中，命名 `{ComponentName}Props`
- 条件渲染使用 `&&` 或三元运算符，复杂分支提取为变量
- 避免过早优化，Demo 中不使用 `useMemo` / `useCallback`

## CSS / Tailwind

- 优先使用 Tailwind 工具类，不使用 CSS 文件
- 复杂样式提取为 Tailwind 组合类时使用 `className` 字符串拼接
- 响应式断点遵循 Tailwind 默认：`sm: md: lg:`
- 不使用内联 `style={}` 属性

## 文件组织

- 导入顺序：React → 三方库 → 内部模块（按路径深度）
- 同一目录下的文件使用相对路径导入
- 组件文件扩展名使用 `.tsx`，纯逻辑文件使用 `.ts`
