# 命名规范

## 通用规则

- 见名知义，禁止 `a`、`tmp`、`data2` 等无意义命名
- 布尔值用 `is` / `has` / `can` 前缀；函数名以动词开头
- 禁止拼音与英文混用（专有业务名词除外）

## 文件命名

| 技术栈 | 规范 | 示例 |
| --- | --- | --- |
| 前端组件 | PascalCase | `CardItem.tsx` / `CardItem.vue` |
| 前端 Hook / 工具 | camelCase | `useCards.ts` / `format.ts` |
| Java 类 | PascalCase，与 public 类同名 | `UserService.java` |
| Python 模块 | snake_case | `user_service.py` |
| 配置文件 | 生态惯例名 | `vite.config.ts`、`application.yml`、`pyproject.toml` |

## 代码命名

| 类型 | TS / Node / 前端 | Java | Python |
| --- | --- | --- | --- |
| 变量 / 函数 | camelCase | camelCase | snake_case |
| 常量 | UPPER_SNAKE_CASE | UPPER_SNAKE_CASE | UPPER_SNAKE_CASE |
| 类 / 接口 / 类型 | PascalCase | PascalCase | PascalCase |
| 模块 / 包名 | camelCase 或 kebab-case | 全小写分层包（`com.xx.service`） | snake_case |
| 事件 / 回调 | `handleXxx` | `onXxx` | `on_xxx` |
| 接口传输对象 | `XxxProps` / `XxxDTO` | `XxxDTO` / `XxxVO` | `XxxSchema` |

## 目录命名

- 全小写：前端复数小写（`components/`）、Java 分层包名（`controller/`、`service/`）、Python snake_case
- 同一层内命名风格必须一致，不混用
