# 命名规范

## 文件命名

| 类型 | 规范 | 示例 |
| --- | --- | --- |
| 组件 | PascalCase | `CardItem.tsx` |
| Hook | camelCase, `use` 前缀 | `useCards.ts` |
| 类型 | camelCase | `card.ts` |
| 页面 | PascalCase | `HomePage.tsx` |
| 样式 | camelCase | `index.css` |

## 代码命名

| 类型 | 规范 | 示例 |
| --- | --- | --- |
| 组件名 | PascalCase | `function CardGrid()` |
| 函数/变量 | camelCase | `addCard`, `handleFile` |
| 常量 | UPPER_SNAKE_CASE | `STORAGE_KEY` |
| 接口 | PascalCase | `interface CardProps` |
| 类型别名 | PascalCase | `type CardList = Card[]` |
| 事件处理 | `handle` + 动作 | `handleSave`, `handleClose` |
| Props 接口 | 组件名 + `Props` | `CardItemProps` |

## 目录命名

- 全部小写 + 复数形式：`components/`、`hooks/`、`pages/`、`types/`
