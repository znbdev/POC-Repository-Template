# 项目结构规范

## 顶层结构

```
points-card-manager/
├── index.html          # Vite 入口 HTML
├── package.json        # 依赖与脚本
├── tsconfig.json       # TypeScript 配置
├── vite.config.ts      # Vite 配置
└── src/                # 源码目录
    ├── main.tsx        # 应用入口
    ├── App.tsx         # 路由配置
    ├── index.css       # 全局样式入口
    ├── types/          # 类型定义
    ├── hooks/          # 自定义 Hooks（逻辑层）
    ├── components/     # 通用 UI 组件
    └── pages/          # 页面级组件
```

## 分层原则

```
pages/      ← 页面容器，组合组件、管理状态
components/ ← 纯展示/交互组件，通过 props 接收数据
hooks/      ← 可复用的状态逻辑，与 UI 无关
types/      ← 全局类型/接口定义
```

## 约束

- `pages/` 可以引用 `components/`、`hooks/`、`types/`
- `components/` 不可以引用 `pages/`
- `hooks/` 不引用任何 UI 组件
- 每个文件默认导出（default export）一个主要功能
