# 构建与部署

## Vite 构建配置

```typescript
// vite.config.ts
export default defineConfig({
  base: process.env.BASE_URL || '/',
  plugins: [react(), tailwindcss()],
})
```

- `base` 通过环境变量 `BASE_URL` 注入，CI/CD 中自动设为 `/<repo-name>/`
- 使用 `@tailwindcss/vite` 插件，无需 PostCSS 配置文件

## CI/CD 流水线

工作流文件：`.github/workflows/deploy.yml`

### 触发条件

```yaml
on:
  push:
    branches: [main]
    paths:
      - 'points-card-manager/**'
      - '.github/workflows/deploy.yml'
  workflow_dispatch:   # 手动触发
```

### 执行步骤

```
1. actions/checkout@v4
2. actions/setup-node@v4    (Node 20, 缓存 npm)
3. npm ci
4. npm run build             (BASE_URL 自动注入)
5. actions/upload-pages-artifact@v3  (上传 dist/)
6. actions/deploy-pages@v4           (部署到 Pages)
```

### 一键部署

```bash
./deploy.sh
# → git add -A → git commit → git push origin main
```
