## 0. 新建工程必备件（硬性规则）

<!-- 任何从本模板起步的工程必须全部满足，缺一不可。
     既是交付验收标准，也是 AI 开工前的自检清单。 -->

1. **PRD 文档**：`docs/PRD.md` —— 业务需求、页面/功能清单、验收标准。
2. **技术栈文档**：`docs/TECHSTACK.md` —— 技术选型及理由、架构决策记录。
3. **使用文档**：仓库根目录 `README.md`（快速开始 + 常用命令，面向开发者）；
   面向非开发人员的操作手册放 `docs/USAGE.md`（如无该受众可省略，但 README 必须有）。
4. **配置统一走 `.env`**：所有环境变量集中在根目录 `.env` 管理；
   提交 `.env.example`（只放键名与占位说明，**禁止提交 `.env`**，gitignore 必须覆盖）；
   代码中禁止硬编码密钥/主机/端口等配置；CI/CD 用平台 Secrets 注入**同名**变量。
5. **启动脚本**：根目录提供 `start.sh`（或 `Makefile`），一条命令完成
   依赖安装 + 启动开发/服务；所有文档中的启动方式**只引用该脚本**，
   避免 README、CI、脚本三处各写一套命令。
