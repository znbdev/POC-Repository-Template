## 3. 技术验证结果

### 3.1 技术方案评估

#### 3.1.1 技术选型对比
| 方案 | 优势 | 劣势 | 评分 |
| --- | --- | --- | --- |
| React 19 + TS | 类型安全、生态成熟、HMR 极快 | 包体积 ~240KB gzip 后 ~77KB | 9/10 |

#### 3.1.2 最终选择

1. 纯前端方案，零服务器成本
2. 开发体验好（TypeScript 类型安全、Vite HMR 毫秒级）
3. 部署链路成熟稳定

## 8. 经验教训

### 8.1 成功经验
1. `gh api` CLI 可完全替代 Web 界面操作 GitHub 配置，适合自动化场景
2. `actions/deploy-pages` 首次运行时需确保 Pages 已启用，否则返回 404
3. Tailwind CSS v4 `@import "tailwindcss"` 相比 v3 配置大幅简化

### 8.2 改进建议
1. 图片量增大后可迁移至 IndexedDB 存储
2. 可添加图片懒加载优化列表滚动性能
3. 建议为仓库设置 Pages 环境变量自动注入 base 路径

### 8.3 最佳实践
- 前端图片上传始终做 Canvas 压缩，避免 LocalStorage 快速超限
- CI/CD 流水线中 `working-directory` 与 `paths` 触发条件需保持一致
- 使用 `concurrency` 取消正在进行的相同 workflow，避免重复部署
