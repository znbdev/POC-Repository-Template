# 积分卡管理（Points Card Manager）—— 产品需求文档

> 版本：v1.0  
> 最后更新：2026-06-20  
> 状态：草稿

---

## 1. 产品背景

超市、商场、会员店场景下，消费者持有大量积分卡/会员卡。实体卡不便携带，电子卡分散在各品牌 App 中，查找与使用体验割裂。需要一个**轻量、快捷**的工具，将所有积分卡条形码集中管理，在收银台快速调出扫码。

---

## 2. 产品目标

- 收银台场景下 **3 秒内** 找到目标积分卡并展示条形码
- 无需注册、无需网络，**离线可用**
- 零使用门槛，打开即用

---

## 3. 用户角色

| 角色 | 描述 | 核心诉求 |
| --- | --- | --- |
| 普通消费者 | 持有 3-20 张积分卡 | 快速添加、快速查找、扫码出示 |
| 家庭管理员 | 管理全家积分卡 | 批量录入、统一管理 |

---

## 4. 功能需求

### P0（MVP 必达）

| ID | 模块 | 功能 | 描述 |
| --- | --- | --- | --- |
| F-001 | 首页 | 卡片列表 | 以网格形式展示所有积分卡，按添加时间倒序 |
| F-002 | 首页 | 空态引导 | 无卡片时展示引导文案和添加入口 |
| F-003 | 上传 | 拍照录入 | 调用相机拍摄条形码，手动补充商户名和卡名 |
| F-004 | 上传 | 相册录入 | 从相册选择条形码图片 |
| F-005 | 上传 | 图片压缩 | 上传时自动压缩图片以减少存储占用 |
| F-006 | 查看 | 条形码大图 | 点击卡片全屏展示条形码，便于扫码设备识别 |
| F-007 | 查看 | 关闭大图 | 点击关闭或空白区域返回列表 |

### P1（重要）

| ID | 模块 | 功能 | 描述 |
| --- | --- | --- | --- |
| F-008 | 管理 | 删除卡片 | 左滑或长按删除，需二次确认 |
| F-009 | 管理 | 编辑卡片 | 修改已保存的商户名/卡名 |
| F-010 | 查看 | 屏幕常亮 | 大图模式下阻止屏幕休眠 |

### P2（后续）

| ID | 模块 | 功能 | 描述 |
| --- | --- | --- | --- |
| F-011 | 管理 | 搜索 | 按商户名/卡名搜索 |
| F-012 | 管理 | 排序 | 按名称排序或手动拖拽 |
| F-013 | 数据 | 导出/导入 | JSON 格式备份与恢复 |
| F-014 | 数据 | iCloud 同步 | 多设备数据同步 |

## 5. 用户故事

### 5.1 日常添加

```
As a 消费者
I want to 打开 App 拍照录入新办的超市积分卡
So that 下次购物时直接出示条形码
```

### 5.2 收银台使用

```
As a 消费者
I want to 在收银台快速找到山姆会员卡并放大条形码
So that 收银员可以扫码积分
```

### 5.3 首次使用

```
As a 新用户
I want to 打开 App 时有明确引导告诉我怎么添加卡片
So that 不需要学习成本
```

## 6. 成功指标

| 指标 | 目标值 | 衡量方式 |
| --- | --- | --- |
| 添加一张卡耗时 | < 30 秒 | 用户测试 |
| 找到目标卡耗时 | < 3 秒 | 用户测试 |
| 首屏加载时间 | < 2 秒（3G） | Lighthouse |
| 应用体积 | < 500KB | 构建产物统计 |
| 可存储卡片数 | ≥ 30 张 | LocalStorage 限额测试 |

---

## 7. 功能边界

### 包含

- 拍照 / 相册上传条形码图片
- 手动输入商户名和卡名
- 列表展示 + 空态引导
- 全屏大图展示
- 卡片删除和编辑
- 数据导出导入

### 不包含

- 用户注册 / 登录系统
- 后端服务 / 数据库
- 条形码 OCR 自动识别
- 多设备实时同步
- 推送通知
- 支付功能

---

## 8. 设计约束

- **纯前端**：零服务器，所有数据存于浏览器
- **离线可用**：不支持网络也能正常使用
- **移动优先**：手机为第一屏，平板适配
- **单设备**：数据不跨设备同步

## 9. 术语表

| 术语 | 说明 |
| --- | --- |
| 积分卡 | 超市/商场发行的会员积分卡 |
| 条形码 | 卡面上用于扫码识别的一维条码 |
| 商户名 | 发卡商家名称，如"山姆"、"盒马" |
| 卡名 | 卡片具体名称，如"山姆会员卡" |
| Base64 | 图片转为文本字符串的编码方式 |
